# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

## Overview
This repository demostrates basic spatial anaylsis tutorials with the use of QGIS. It explores the open source of QGIS to process GIS data. Using QGIS to manipulate and map spatial data. The skills presented in this project are: mapping layout, mapping projections, vecotr and raster calculations, basic queries, manipulating features and attributes using SQLs.

## Software Environment
QGIS Desktop 4.0.1
Windows

## Completed Tutorials
* Making a Map
* Working with Projections
* Working with Attributes
* Importing Spreadsheets or CSV files
* Basic Vecotr Styling
* Basic Raster Styling and Analysis
* Performing Table Joins
* Performing Spatial Joins
* Performing Spatial Queries
* Georeferencing Aerial Imagery

## Skills Demonstrated
